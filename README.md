# 数学小花园 · Math Garden

面向约 6 岁孩子的中文加减法练习应用。随机出题、数字键盘 / 选择作答、十格框图解、结果总结、错题复习和 A4 练习纸打印。

## 本地运行

需要 Node.js 24 或更新版本。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## 练习规则

- 小种子：5 以内；小花苗：10 以内。
- 小花园：20 以内，不进位、不退位。
- 小挑战：20 以内，每种运算至少包含 3 道进位或退位题。
- 每轮 15 / 20 题，支持加法、减法或混合；同轮无相同题目，尽量避免加数交换。
- 小范围题池不足以避开交换加数时给出提示，不进行无限重试。
- 首次答错可以再试；两次答错展示答案与图解。不计时、不扣生命值。
- 首次答对、重试、求助分别记录。错题复习为独立的小练习。

## 打印

从首页生成练习纸，或从测验 / 结果页打印当前这轮题目。预览、打印与单独答案页共用固定题目；点击「换一套题」才重新生成。

推荐 A4 竖向、100% 缩放，关闭浏览器页眉页脚。每页 15 / 20 题，可额外打印一页答案。浏览器提供的「保存为 PDF」和移动端打印入口因设备而异。

## 发布到 GitHub Pages

仓库：https://github.com/soki/math-garden

1. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. 推送到 `main` 或手动运行 **Deploy Math Garden to GitHub Pages** 工作流。
3. 工作流依次执行 `npm ci`、测试、类型检查和构建，再发布 `dist/`。
4. 预期网址：https://soki.github.io/math-garden/

Vite 使用相对资源路径，可部署到仓库子路径；页面不使用 History 路由。

## 结构

- `src/questions.ts`：有限题池、难度过滤、抽题配比、选项。
- `src/session.ts`：尝试次数、进度和结果统计。
- `src/main.ts`：页面、输入、图解、打印、本地保存。
- `src/art.ts`：本项目绘制的 SVG 小花园与图标。
- `src/style.css`：响应式布局、动效偏好和 A4 打印排版。
- `tests/questions.test.ts`：出题和测验状态的自动检查。

## 数据与兼容性

无需账号、服务端、外部字体、分析脚本或网络图片。练习设置和当前一轮结果保存于本浏览器 localStorage；姓名仅存在打印预览的内存中，不写入本地存储，也不上传。存储不可用时仍可练习。

按浏览器可用宽高布局，支持横竖屏切换。安卓平板 / iPad 实机触摸与打印、实体打印机输出、儿童试用仍需实际验收。浏览器视口模拟仅验证布局，不能替代设备验收。
